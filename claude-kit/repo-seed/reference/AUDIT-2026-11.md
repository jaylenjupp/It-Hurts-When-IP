# Code audit — v1.13.1 (main @ 20b1ec9), November 2026

Read-only context for planning. Written from a read of the repo before this round started. Line numbers refer to that commit. Do not edit this file; record fixes in `docs/PROGRESS.md`.

## Safety / security
1. **Helper socket is world-writable.** `helper-tool/src/main.rs:16-19` runs `chmod 777` on `/var/run/com.ithurtswhenip.helper.sock`. Any local process or user can ask the root helper to change any service's IP or set DHCP. → Phase 2.
2. **Shell injection in the app.** `src-tauri/src/platform/macos.rs:31-32` builds `networksetup -getinfo '<interface>'` and runs it with `sh -c`. A service name containing `'` breaks out of the quotes. Runs as the user, not root, but still arbitrary command execution from a crafted service name. → Phase 2.
3. **No input validation in the helper.** `set_static_ip` passes `interface`, `ip`, `subnet`, `gateway` straight to `networksetup -setmanual` (argv, so no shell injection there, but anything `networksetup` accepts is applied as root). Empty strings default via `unwrap_or("")`. → Phase 2.
4. **Errors only read from stderr** (`main.rs:78`, `:97`). If `networksetup` reports on stdout (as `netsh` does on Windows), failures can be reported as success. → Phase 2, confirm real behaviour with fixtures.

## Uninstall / leftovers (likely contributors to "broken adapter" reports)
5. **Two inconsistent uninstallers.** Root `Uninstall Script.command` still targets the pre-rename `com.ipswitcher.*` identifiers and `~/Library/Application Support/com.ipswitcher.switcher`; it doesn't touch the current helper. The bundled one (heredoc in `build-pkg.sh:111-160`) targets current ids only, doesn't handle legacy ids, receipts, caches/WebKit data, or revert any network settings. → Phase 1.
6. **No record of original settings.** The app never stores what a service looked like before it changed it, so neither uninstall nor support can restore it. A service left on a static address from a show network looks "bricked" on the next network. → Phase 2 journal; Phase 1 offers DHCP-per-service as a stopgap.
7. **Legacy helper may still run on upgraded machines.** `preinstall` only `pkgutil --forget`s the old receipts; it doesn't stop/remove a `com.ipswitcher.helper` daemon if one is still loaded. → Phase 1 (rescue script handles legacy).
8. Pkg uses `launchctl load/unload` (legacy subcommands). Works today; check on current macOS. → note in Phase 1/2.

## Correctness
9. `get_interfaces` (`macos.rs:11-28`) filters with a shell pipeline and keeps the `*` prefix of disabled services, so a disabled service shows as `*Name` and later commands target a non-existent name. → Phase 2.
10. `get_ip_info` returns `"—"` for missing fields and sets `is_dhcp` on any line containing "DHCP"; brittle but fine for current output. Covered by fixture tests in Phase 0.
11. `save_config` uses `unwrap()` on serialisation and ignores write errors (`fs::write(...).ok()`), so a failed save is silent. → consider in Phase 4 config work.
12. Update checker (`update.rs`) is unauthenticated against the public repo and only sees published releases (good — draft dev builds stay invisible). `/releases/latest` also excludes pre-releases.

## Platform
13. Windows code: `service-tool/` (Windows service, named pipe), `installer-iss/installer.iss`, `src-tauri/src/platform/windows.rs`, `tauri.windows.conf.json`, Windows-specific JS for the custom titlebar. Parked in Phase 0; keep the `platform/` abstraction intact.
14. Earlier Windows troubleshooting left a Wi-Fi adapter without gateway connectivity (routing table / Winsock suspected). Windows colleagues won't get the Phase 1–3 fixes until Windows returns — owner is aware.
